# Schema 实验流程与分析说明

这项实验研究人怎样利用已有知识类别学习和选择，以及奖励、风险和新颖性怎样改变这一过程。绘画按画家、语句按作者形成 schema；任务要求学习这些类别的特征，在决策时辨认同一作者的项目。绘画与语句任务的参与者不同，分别分析更合适。[Workshop 4.2，第1–2页；Information sheet，第1–2页]

## 已确认的实验流程

1. 实验前填写问卷，随后在探索与决策阶段间交替进行。
2. 探索时自由浏览画作或语句，学习作者类别。第一次探索至少10分钟，之后每次至少3分钟，然后可自行进入决策。[Workshop 4.2，第1页]
3. 决策屏幕提供20个项目，目标是选出属于同一作者的4个。没有单独的决策时限，但整场实验有总时限。Workshop 6补充：每轮有两个决策屏幕，因此行为表的一条决策记录不等于生理表的一整轮。[Workshop 4.2，第1页；Workshop 6，第1–2页]
4. Workshop 4.2写明，在35分钟后完成第一个决策阶段后休息5分钟，再继续任务；部分组在休息后改变风险或引入新类别。实验后还有体验问卷。[Workshop 4.2，第1页；Information sheet，第2页]

时长材料存在不同口径：Information sheet写至少60分钟、之后可结束、上限90分钟；Workshop 4.2第1页也写上限90分钟，但第2页解释汇总数据时说总时间75分钟、通常75分钟。不能把所有参与者视为固定75或90分钟；需要进一步确认本地数据版本及时间基准。

## 奖励和实验条件

每个所选项目的基础收益由其schema决定，为2–6便士。4项全部来自同一作者时，收益乘3；低风险条件下，3项来自同一作者也可获得乘2奖励，高风险没有这项额外保障；具体哪些收益乘2，见下方2019绘画程序的实现说明。因此这里的风险至少明确体现为是否奖励部分正确，而不应猜测成随机输钱概率。[Workshop 4.2，第1–2页；schema intro，第1–2页]

六组为：低风险保持Lc、高风险保持Hc、低转高LH、高转低HL、低风险新颖性L、高风险新颖性H。新颖性组休息后将10个schema中的5个换成新的，需要重新学习。[Workshop 4.2，第1页]

课程网页对ZJE学生数据另作说明：2019年采用新颖性条件，2024年采用无新颖性的风险切换条件；该网页说新schema在35分钟后首次开始的探索阶段引入。这个年度说明不能直接替代Edinburgh材料的休息规则。

## 收集的数据与字段

|数据|含义与分析边界|
|---|---|
|行为汇总|每人每决策屏幕一条记录，包括轮次、相对时间、风险、切换、新颖性、收益等|
|payoff|实际按所在风险规则获得的屏幕收益|
|performance|低风险时等于payoff；高风险时按低风险奖励规则重新计算，供跨风险比较。它不是成功率|
|AEPpayoff|Workshop 4.2定义为依据实际payoff的此前轮次平均期望表现；本地两个版本不一致，仍须核实计算实现及首轮处理|
|RPE|文档描述为上一轮payoff相对AEP的偏差；精确索引和AEP时间窗口须核对，不能只凭文字指定公式|
|DecBias|不含奖励倍数的所选项目平均价值，反映偏向较高或较低基础收益的类别；须确认本地表是否提供|
|AC|4项同类计1，3项同类计0.5，否则0；须确认本地表是否提供或能由原始选择重建|
|瞳孔|每轮探索及两个决策屏幕的中位值，减去该参与者最初10分钟的均值。负值正常；不直接等于注意力或压力|
|心率|经过处理的心率及任务条件；语句心率有已知错误提示，暂不支撑主要结论|
|眼动|时间戳、注视坐标、屏幕、选择序号、注视项目、schema及最终选择，用于估计浏览策略|

行为字段依据Workshop 4.2第2页；生理与眼动依据Workshop 6。Information sheet列出的面部录像、皮电、唾液皮质醇等是可能采集的指标，不代表本地已有这些完整数据。课程网页明确2026课堂演示不采集生物测量或唾液，也不提供金钱报酬；不要与Edinburgh原始实验混为一谈。

课程网页还说明原始MAT字段：Explpics/Expltimes/Explactions记录探索项目、时点和入口；Decmaps记录每屏20个项目，Decpics记录4次选择，Dectimes记录选择时间；Payoffs为不含奖金的项目收益，Moneys为含奖金的累计金额。原始项目编号可用ceil(x/36)（绘画）或ceil(x/28)（语句）映射schema，但不能把此公式直接套用到本地眼动PicID这种屏幕位置编号。原始MAT时间说明为秒，不能据此断言眼动Timestamp也为秒。

## 拟议分析及新的方法依据

现有analysis/exploratory_methods.md仍是探索方案，尚未算出效应或进行正式模型拟合。

- 学习：分别画个人performance随轮次或相对时间变化；payoff用于实际奖励体验。跨风险比较以performance为主，避免低风险奖励制度造成机械优势。[Workshop 4.2，第3页]
- 瞳孔：同一人同一轮先平均可用决策值，再与探索值配对；不能直接解释为注意力因果效应。
- 风险与新颖性：按整段实验识别组别，对齐休息前后，比较相应保持组；同时考虑学习进程和个人起点。
- 眼动：按每次选择估计所选项目注视占比及浏览类别范围，再汇总到个人；保留时间断点并检查覆盖率。
- 正式模型：课程建议混合效应模型处理动态变化和重复测量。研究AEP/RPE时必须同时考虑时间或轮次，防止把随时间共同上升误判为反馈作用。[Workshop 4.2，第3页]
- 绝对学习水平：上升趋势只说明相对改善。是否超过随机选择还需根据真实决策集合构造机会基线，不能随意采用1/20。[Workshop 4.2，第3页]

## 探索界面与反馈时点的程序证据

以下细节来自 Schema paintings.zip 中 new_paintings_2019_new.mlapp 的 matlab/document.xml，以静态读取方式核对，没有运行实验。它是课程提供的2019绘画程序，尚未确认就是本地Edinburgh CSV的采集版本，也未确认语句程序完全相同。

### 参与者在探索时看到什么

界面是一间“在线画廊”：左侧列表用“画家名 — 作品标题”列出项目；选中后显示画作及作者标题；右侧另有三个同画家的其他作品入口，可以沿着同一个作者继续浏览，也可以回列表换作者。程序记录打开了哪幅图、何时打开、从列表还是三个关联入口中的哪一个进入。[startupFcn、ListBoxValueChanged、BRelated1/2/3ButtonPushed、createComponents]

该版本初始启用10位画家，每位36幅作品中随机划出18幅作探索池，另外18幅作决策保留池。探索池中的项目不等于参与者实际都看过，实际浏览需依据Explpic记录判断。

### 决策屏幕如何构成

每屏20幅画，来自5位画家，每位4幅，位置打乱；每位的4幅由探索池中1幅和保留池中3幅组成。一轮的第二个决策屏幕使用另外5个schema。所谓“旧/新作品”是相对素材池而言，不能保证那幅探索池作品已被此人浏览过，也不能把保留池作品称作每轮都首次见到。[ContinueToTestButtonPushed]

点击选中的作品后，该按钮立即禁用并变色，不能撤回；程序记录该次选择和时间。选满4项后不能继续加选。[Button1–20ButtonPushed、RewardUpdate]

### 反馈并非只在整轮结束后出现

每次点击都会调用RewardUpdate，更新屏幕底部对应选择的画家名及基础收益。Payoff1–4控件直接属于主窗口，在决策屏幕中可见；这与直到选满4项才显示的Feedback面板不同。第4次选择后显示完整反馈，包括4项作者、各项收益、奖金倍数、整屏总收益，并开放继续按钮。第一屏后可进入第二屏，第二屏后可返回探索。[ContinueToTestButtonPushed、RewardUpdate、createComponents]

因此，该绘画版本的第2–4次选择可能利用同屏前面选择给出的作者/收益信息；不能把4次选择当成互不影响、完全没有反馈的独立判断。眼动策略也宜按第几次选择分开讨论。上述为静态代码确定的显示逻辑，未做运行界面或历史采集日志验证。

### 程序还显示的版本边界

低风险“3项同类双倍”的具体实现是三项同值项目收益乘2，再加剩下一项基础收益，而不是把四项总和全部乘2。4项同值则四项总和乘3。代码依据收益是否相同来检测，课程文字依据作者是否相同；两者等价需要同屏不同类别具有不同基础收益。用于重建本地实际收益前仍须核对payoff表、刺激配置和采集版本。[RewardUpdate]

该程序通常把后续探索最短时间设为3分钟，但在新颖性引入、风险切换后首段及控制组中点附近又设为10分钟。程序新颖性列表明确包含schema 11–15；这为这些编号的用途提供版本内证据，但不能直接修复本地眼动标签。它与Workshop 4.2所述“中途休息5分钟”不能未经核对合并成同一时间流程。[ContinueToExplButtonPushed]

## 尚待核实

- 本地CSV对应哪一批实验、实际时长及时间归一化基准。
- 分组是否随机及具体分配方式；不要由组间差异直接推断因果。
- 本地AEP版本差异、RPE的逐轮索引、首轮处理及是否存在未说明的平滑。
- 瞳孔两个phase=1记录与具体屏幕的映射，以及心率与行为轮次映射。
- 眼动Timestamp单位、非递增时间戳、Paintings_36阶段标签异常；2019绘画程序中schema 11–15用于新颖性替换，但本地数据版本对应仍须核对。
- 本地文件是否具备AC、DecBias和完整问卷；原文介绍这些数据不等于当前目录全部具备。

Edinburgh schema results.pdf是既往结果图，尚未逐图视觉核读，不能当作本项目已复现的结果。
