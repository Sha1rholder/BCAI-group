项目名称：探索图式情境中决策的生物特征

## 研究目的

本研究旨在了解结构化的知识框架如何影响不同主题下的学习与决策。我们将探索，把知识组织成具有不同熟悉程度和情感内涵的图式，会如何影响人们对这些知识（图式项目）的探索。我们还将研究不同的金钱结果如何影响这一过程
